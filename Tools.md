# AI and Tool Usage Declaration

## CS203D Project : Live Leaderboard with Rank Queries

Size-Augmented AVL Tree vs Unbalanced Binary Search Tree

## 1. Purpose of AI Assistance

AI tools were used as supporting tools during the development of this project. Their purpose was to assist with understanding, development, testing, debugging, documentation, and analysis.

The core project involved implementing and evaluating data structures, integrating them into a leaderboard application, testing their correctness, and benchmarking their performance.

## 2. Areas Where AI Assistance Was Used

AI assistance was used in the following areas:

### Conceptual Understanding

- Understanding AVL Tree balancing and rotation cases.
- Understanding subtree-size augmentation.
- Understanding rank and select operations.
- Comparing the expected complexities of balanced and unbalanced trees.
- Interpreting worst-case BST behaviour.

### Development and Debugging

- Assistance with reviewing implementation logic.
- Identifying potential edge cases and bugs.
- Debugging compilation and runtime issues.
- Reviewing interactions between the application and tree implementations.
- Assistance during development of the graphical interface.

### Testing

- Assistance in understanding differential testing.
- Reviewing test coverage and invariant checks.
- Interpreting test failures and execution output.
- Considering edge cases and worst-case insertion orders.

### Benchmarking and Analysis

- Assistance with benchmark methodology and metric interpretation.
- Understanding insertion, rank, select, height, and rotation measurements.
- Analysing random and sorted insertion behaviour.
- Assistance with plotting, result presentation, and report writing.

### Documentation

- Assistance with drafting and organizing the README.
- Assistance with preparing the report.
- Assistance with explanations of design choices and limitations.

## 3. Responsibility and Verification

AI-generated suggestions were treated as assistance and not as automatically correct solutions.

The team reviewed, modified, tested, and integrated the project components. The team remains responsible for the submitted implementation, the reported experimental results, and understanding the design decisions and algorithms used.

## 4. Tools Used

- **ChatGPT and Claude :** Assistance with explanations, debugging, code review, GUI development, testing discussions, benchmarking interpretation, and documentation.
- **C++ compiler (g++):** Compilation and execution of the application, tests, and benchmark programs.
- **Python:** GUI functionality, plotting, and benchmark visualization.
- **Tkinter:** Graphical user interface development.
- **Matplotlib:** Benchmark result visualization.
- **Git and GitHub:** Source control and repository management.

## 5. Declaration

AI tools were used to support the development process. The submitted project was reviewed and tested by the team, and the team takes responsibility for the final implementation and report.
